## 1. 1分版（エレベーターピッチ）

> 大人向けの語彙力クイズです。四字熟語・慣用句・故事成語・敬語・カタカナ語など7分野、681語・1,362問。**全部自作**です。
>
> 4択に答えるだけ。連続正解で倍率が上がり、結果で段位が出て、出会った語は語彙帳に残ります。
> 「今日の修行」を毎日10問やると連勝日数が伸びる。習慣にする入口と、時間攻め・真剣勝負で燃える入口の両方があります。
>
> 通信なし・端末内保存。Web版は公開済みで、**iOSプロジェクトも構築済み、ビルドが通ることまで確認済み**です。
> 残りは実機確認とApple Developerの登録だけ。コツコツの次に申請できます。

### 2-1. 何のアプリか・ねらい（30秒）

- 大人の語彙力を鍛える4択クイズ。学習アプリではなく「ゲーム」として設計
- 大人の語彙は測る機会がない。「知っているつもり」の語を、遊びながら直す
- Web版は公開中、iOSプロジェクト構築済み

### 2-2. デモ（3分）※台本

**① 今日の修行（1分30秒）**
> 「毎日10問の『今日の修行』です」（3〜4問解く。1問はわざと間違える）
> 「『語→意味』と『意味→語』の両方向で出ます。連続で当てると倍率が上がって、1問の重みが変わります。間違えると倍率が戻るので後半ほど緊張します」

**② 結果画面（30秒）**
> 「結果で段位が出ます。見習いから名人まで。ここに『取りこぼした語を今すぐ復習』があって、**間違えた語だけを即やり直せる**。悔しいうちに覚え直す設計です」

**③ モードと語彙帳（1分）**
> 「モードは5つ。時間攻めは60秒、真剣勝負は3ミスで終了、弱点復習、分野別」（時間攻めを10秒だけ）
> 「語彙帳には出会った語が全部残ります。苦手・習得済みで絞れる。自分の語彙の地図になります」
> 「称号は経験値で育ちます」

**④ 機内モード（30秒）※必ず見せる**
> （機内モードにする）「このまま全部動きます。**通信なし**。語彙データもすべてHTMLの中です」

### 2-3. 収録と品質（30秒）

- 7分野 × 3難易度。初級100点・中級120点・上級150点
- 教育カテゴリは審査で「コンテンツの質」を見られる。**681語すべて自作**（辞書的な定義を参照して独自に執筆）。引用・転載なし。引き渡し手順にも明記済み
- 語の追加は `index.html` の配列に1行足すだけ

### 2-4. 現状（30秒）

- Web版 完成・公開中、PWA対応
- iOSプロジェクト構築済み（Capacitor、Bundle ID `work.ltv.goidojo`）。GitHub Actions の macOS 環境で署名なしビルドが通ることを確認済み
- 触覚フィードバック・ローカル通知（毎日同時刻の「今日の修行」）を実装
- 申請文面は下書き済み

### 2-5. 次のステップとお願い（30秒）

- 残り：Xcode のある環境で `pod install` → 実機で触覚・通知・データ永続化を確認、スクリーンショット3サイズ、Apple Developer Program
- 費用は Apple Developer Program（年12,800円）だけ
- **お願いしたいこと**：コツコツの次に語彙道場を申請する順番でよいか。実機確認用のiPhoneを借りられるか

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| 語の意味は正確？ | 辞書的な定義を参照して自分で書いた。誤りが見つかれば `index.html` の1行を直すだけで、Web版は数分で反映される |
| 著作権は大丈夫？ | 語彙データはすべて自作。辞書・問題集からの引用・転載はない。教育カテゴリの審査対策として引き渡し手順にも明記 |
| 語を増やせる？ | 1行追加するだけ。目標は1,000語。同じ分野内で意味文が重複すると4択が成立しないので、その点だけ注意 |
| 誰向け？ | 大人（就活・ビジネス・読書好き）。内容は一般的な語彙なので年齢制限は 4+ |
| 通知は？ | iOS版はローカル通知（端末内・通信なし）で毎日同時刻に「今日の修行」を知らせる。Web版は開いたときの表示のみ |
| データは？ | 端末内のみ。iOS版は localStorage とネイティブ保存に二重化して消失対策。App Store のプライバシーは「収集しません」 |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用（連勝日数・語彙帳・称号）に加え、触覚とローカル通知を実装。コツコツと同じ根拠 |
| 音は？ | 効果音・BGMは Web Audio で合成。音源ファイルなし |
| Android は？ | Web版（PWA）がそのまま動く。必要なら Capacitor で Android も生成できる |
| 今後の候補は？ | 間隔反復（間違えた語を1日後・3日後・7日後に再出題）、結果のシェア画像、1,000語への増量 |

## 4. 話し方のコツ

- 最初の30秒で「全語自作」「iOSは申請一歩手前」「通信なし」の3点を言い切る
- デモは**実際に問題を解く**。わざと1問間違えて「取りこぼし復習」を見せる
- 「取りこぼし復習」と「機内モードで動く」の2か所は必ず見せる
- 数字は3つまで（681語／7分野／10問）。多く言わない
- 最後は「お願いしたいこと」を具体的に言って終わる
