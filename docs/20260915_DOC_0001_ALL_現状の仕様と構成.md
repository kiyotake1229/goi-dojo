## 仕様

### 画面と機能

画面は4つ。HTMLの `section` で、id は `s-home`（ホーム）、`s-play`（出題）、`s-result`（結果）、`s-book`（語彙帳）。切り替えは関数 `show`。

**ホーム（`s-home`、描画は `renderHome`）**

- 今日の一語（日付で決まる1語）
- 称号・次の称号までの経験値・経験値バー
- 連勝日数・習得数（N / 681）・正答率
- モード4つ（`#mlist`）と分野別ボタン7つ（`#catwrap`。分野ごとに「習得数 / 語数」）
- 今日の修行のお知らせ（`#remind`。iOS版だけ表示）
- 語彙帳・効果音 ON/OFF・BGM ON/OFF のボタン
- 「681語 / 1362問 収録」の表示と「記録を消す」（`btn-reset`）

**モード（定数 `MODE`、出題リストは関数 `start` で作る）**

| キー | 表示名 | 出題数 | 時間制限 | 出題範囲 | 入口 |
|------|--------|--------|----------|----------|------|
| `daily` | 今日の修行 | 10問 | なし | 全分野から日付で決まる10語。同じ日は同じ問題 | ホーム |
| `time` | 時間攻め | 60秒で解けるだけ | 全体60秒 | 全語をシャッフル。尽きたら再シャッフル | ホーム |
| `survival` | 真剣勝負 | 3回ミスで終了 | 1問12秒（時間切れはミス） | 全語をシャッフル | ホーム |
| `review` | 弱点復習 | 最大12問 | なし | 苦手な語（`weakList`）から。0語なら始まらない | ホーム |
| `cat` | 分野別 | 最大12問 | なし | 選んだ分野の語から | ホームの分野ボタン |
| `fix` | 取りこぼし復習 | 取りこぼした語の数 | なし | 直前に間違えた語。5語未満なら同じ分野の未習得語で5問まで補う | 結果画面の「取りこぼした N 語を今すぐ復習」 |

**出題方式（`makeQ`・`nextQ`）**

- 4択。1問ごとに半々の確率で向きが決まる。「この語の意味は」（語→意味）か「この意味の語は」（意味→語）。
- 誤答肢3つは、正解と同じ分野の他の語からランダムに選ぶ。難易度は問わない。
- 今日の修行だけは、日付から作る乱数（`mulberry32` と `seedOf`）を使う。向き・選択肢も同じ日なら同じ。
- 答えると解説シート（`#sheet`）に語・読み・意味が出る。「つぎへ」で次の問題へ。
- 時間攻めで正解したときだけ、1.25秒後に自動で次へ進む。
- PCではキー 1〜4 で回答、Enter または Space で次へ進む。

**スコアと倍率（`answer`）**

- 正解の得点 = （基本点 + 速さボーナス）× 倍率。四捨五入する。
- 基本点（`BASE`）: 初級100 / 中級120 / 上級150。
- 速さボーナス: 0〜60点。答えるまでが速いほど高く、8秒以上で0。全モード共通。
- 倍率: 1 + 連続正解数 × 0.1。上限3倍。1問目の正解で×1.1、20問連続で×3.0。
- 不正解・時間切れ: 0点。連続正解数が0に戻る。
- 経験値: 正解1問ごとに 10 + (連続正解数×2、上限20)。結果画面を出すときに累計（`S.exp`）へ足す。
- 自己最高記録: モードごとに `S.best` に保存。分野別は7分野で1つの記録を共有。ホームに出すのは時間攻めと真剣勝負のBESTだけ。

**段位（結果画面の判子。定数 `RANKS`。その回のスコアで判定）**

| 段位 | スコア |
|------|--------|
| 名人 | 3000以上 |
| 師範 | 2200以上 |
| 皆伝 | 1500以上 |
| 目録 | 950以上 |
| 初伝 | 550以上 |
| 門下生 | 250以上 |
| 見習い | 0以上 |

真剣勝負で3回ミスして終わったときは、段位ではなく「不覚」と出る。

**称号（ホームに表示。定数 `TITLES`。累計経験値で判定）**

| 称号 | 入門 | 見習い | 門下生 | 初伝 | 中伝 | 奥伝 | 皆伝 | 師範 | 名人 | 語聖 |
|------|------|--------|--------|------|------|------|------|------|------|------|
| 必要経験値 | 0 | 120 | 350 | 800 | 1600 | 2800 | 4500 | 7000 | 10500 | 15000 |

**連勝日数・習得・苦手**

- 連勝日数: 今日の修行を終えた日に更新する（`end`）。前回が昨日なら+1、それ以外は1に戻る。1日1回だけ数える。
- 習得（`isGot`）: 正解数が1以上、かつ正解数 > 不正解数。
- 苦手（`weakList`）: 不正解数が1以上、かつ不正解数 ≥ 正解数。

**結果画面（`s-result`、処理は `end`）**

モード名、段位の判子、スコア、自己最高記録の表示、正解数、正答率、最大連答、獲得経験値を出す。取りこぼした語の一覧も出す（全問正解なら出題した語の一覧）。ボタンは「取りこぼし復習」（ミスがあるときだけ）・「もう一番」・「道場にもどる」。

**語彙帳（`s-book`、処理は `renderBook`）**

一度でも出題された語を表示する（正解・不正解を問わない）。絞り込みは「すべて」「苦手」「習得済み」と7分野。各語に正解数・不正解数を出す。

**演出と音**

- 正解: 画面が光る・斬撃線・紙吹雪（`flash`・`slash`・`burst`）。不正解: 画面が揺れる（`shake`）。
- 効果音とBGMは Web Audio で合成する。音源ファイルはない。
- BGMは最初のタップで始まる（ブラウザの自動再生制限のため）。アプリが裏に回ると止まる。
- 「効果音 OFF」にすると、BGMと触覚も止まる（`ac`・`bgmStart`・`buzz` が `S.mute` を見ている）。
- 動きを減らす端末設定（`prefers-reduced-motion`）では、CSSのアニメーションをほぼ止める。

**分野別・難易度別の語数（`DATA` を集計した値）**

| 分野キー | 分野名 | 初級 | 中級 | 上級 | 計 |
|----------|--------|-----:|-----:|-----:|---:|
| `goi` | 語彙 | 52 | 68 | 40 | 160 |
| `yoji` | 四字熟語 | 69 | 47 | 26 | 142 |
| `kan` | 慣用句 | 92 | 29 | 5 | 126 |
| `koji` | 故事成語 | 20 | 11 | 16 | 47 |
| `biz` | 敬語・仕事語 | 47 | 25 | 4 | 76 |
| `kata` | カタカナ語 | 48 | 29 | 9 | 86 |
| `iikae` | 大人の言い換え | 35 | 9 | 0 | 44 |
| 合計 | | 363 | 218 | 100 | 681 |

- 問題数 1,362 は、681語 × 2方向の数（画面では `DATA.length*2` で出している）。
- 読みが空の語は91語（カタカナ語86、大人の言い換え4、慣用句1）。今日の一語と解説シートでは、読みの代わりに分野名を出す。
- 同じ語の重複はない。同じ分野内での意味文の重複もない（集計で確認）。

### データの保存

- 保存先はブラウザの `localStorage`。キーは `goidojo.v1`（定数 `KEY`）。JSON 1件にまとめて保存する。
- 保存するのは、1問答えるごと・結果画面を出すとき・設定を変えたとき（関数 `save`）。
- 中身（初期値は `defState`、実行中は変数 `S`）:

| 項目 | 内容 |
|------|------|
| `best` | モード別の最高スコア |
| `stat` | 語ごとの正解数・不正解数 `{ id: {o, x} }`。id は `DATA` の並び順（0始まり） |
| `streak` | `{last, days}`。最後に今日の修行を終えた日と連勝日数 |
| `dailyDone` | 今日の修行を終えた日（`YYYY-M-D` 形式。ゼロ埋めなし） |
| `exp` | 累計経験値 |
| `mute` | 効果音 OFF |
| `bgmOff` | BGM OFF |
| `remind` | `{on, time}`。お知らせの ON/OFF と時刻（初期値 `20:00`） |

- iOS版の二重保存: `save` で Capacitor の Preferences にも同じキー `goidojo.v1` で保存する。起動時に localStorage が空なら、Preferences から戻す（`nativeRestore`）。WebView側のデータが消えたときの対策。
- 「記録を消す」: 効果音の設定だけ残し、それ以外を初期値に戻す。
- Web版の記録は端末・ブラウザごとに別。サーバーには保存しない。

### 通信と外部リソース

- アプリの処理として外部に送るデータはない。`index.html` に `fetch` などの通信処理はない（`sw.js` の `fetch` はキャッシュ用）。
- 例外として、`index.html` 冒頭の `<link rel="stylesheet">` で Google Fonts を読み込んでいる（`fonts.googleapis.com` / `fonts.gstatic.com`）。フォントは Shippori Mincho B1、Zen Kaku Gothic New、Barlow Condensed。
- 取得できないときは代替フォント（`serif`、`Hiragino Kaku Gothic ProN`、`sans-serif` など）で表示する設定になっている。
- iOS版も同じ `index.html` を同梱しているので、コード上はネット接続時に Google Fonts を取りにいく。
- CDNのJSライブラリは使っていない。アイコン類はHTML内のSVG。画像・音源ファイルの外部読み込みはない。
- `tools/icon-gen.html` も Google Fonts を使うが、開発用でアプリには同梱しない（`sync-web.sh` のコピー対象外）。

**語の追加方法**

1. `DATA` の最後（`].map(` の直前の行）に1行足す。形式は `["語","読み","意味","分野キー",難易度]`。
2. 読みがない語は `""`。難易度は 1=初級 / 2=中級 / 3=上級。
3. 同じ分野の中で意味文を重複させない（4択が成り立たなくなる）。
4. 途中への挿入・削除・並べ替えはしない。id が並び順なので、保存済みの正誤記録が別の語にずれる。
5. Web公開は commit → push。iOS版へは `ios-app/` で `npm run sync`。

**AIが最初に見る場所**

1. `README.md`（状態と残作業）
2. `index.html` の `MODE` → `start` → `nextQ` → `makeQ` → `answer` → `end` の順
3. 保存形式は `defState`、iOS専用の処理は `NATIVE` で検索
4. 申請まわりは `ios-app/岩崎さんへの引き渡し手順.md`

### 既知の制限・注意点

**README・引き渡し手順と実装の食い違い**

- 「通信なし・完全オフライン」と書いてあるが、実装は Google Fonts を外部から読む。オフラインでも動くが、フォントは代替表示になる。App Store の「データを収集しません」や審査備考の「No network access」との整合は、申請前に判断が必要（未確認）。
- 引き渡し手順は「正解した語は語彙帳に蓄積」と書いている。実装では不正解の語も含め、出題された語すべてが載る（README の「出会った語」が正しい）。
- README は語彙帳を「正誤・苦手・習得済みで絞り込み」と書いている。実装の絞り込みは「すべて・苦手・習得済み・7分野」。正誤は各語に回数で表示する。
- 引き渡し手順は「結果画面で段位が判定される」と書いている。真剣勝負で3回ミスして終わると、段位は出ず常に「不覚」になる。段位が出るのは、途中で「やめる」を選んだとき（または全語を解き切ったとき）だけ。

**動作上の注意（コードから確認。実機では未確認）**

- 今日の修行を途中で「やめる」→確認で終えても、1問でも答えていれば「済」になり、連勝日数が増える。
- 連勝が途切れても、次に今日の修行を終えるまでホームの連勝日数は減らない（`renderHome` が `S.streak.days` をそのまま出す）。
- 「効果音 OFF」にすると触覚も止まる。実機で触覚を確認するときは効果音を ON にする。
- お知らせは毎日同じ時刻に届く。今日の修行を済ませた日も止まらない。
- 「記録を消す」でお知らせ設定は OFF に戻るが、予約済みの通知を取り消す処理は呼んでいない。
- 経験値とベストスコアは結果画面を出すときに保存する。途中でアプリを閉じると、その回の分は残らない（正誤記録は1問ごとに保存済み）。
- 取りこぼし復習で13語以上を出すと、進捗表示が「12 / 12」で止まる（`updHud` が `MODE` の `fix` の `n`、つまり12を上限に使う）。13語以上の取りこぼしが出るのは時間攻めのとき。
- 称号が最高の「語聖」になると、次の称号欄に「皆伝の極み」と出る（称号名と合わない）。
- `sw.js` はキャッシュ優先で、保存済みのファイルを取り直さない。`index.html` を更新したら `CACHE` の名前を変えないと、一度開いた端末に古い版が残る。

**環境による差**

- Web版では触覚は `navigator.vibrate` 頼みで、iPhone の Safari では振動しない（`ios-app/README.md` の記載）。
- Web版にお知らせ機能はない（`#remind` はiOS版だけ表示）。
- `@capacitor/app` は依存に入っているが、`index.html` からは使っていない。

**その他**

- ビルド確認は `xcodebuild ... | tail -30` の形で、`pipefail` を指定していない。ビルドが失敗しても成功扱いになるおそれがある。結果はログの `BUILD SUCCEEDED` で確かめる。

- 未実装: 間隔反復、結果のシェア画像生成（README「今後の候補」）。
