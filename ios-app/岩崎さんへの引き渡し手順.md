# 岩崎さんへ — 「語彙道場」iOSアプリ ビルド・申請手順

岩崎さん

語彙力を鍛えるクイズゲーム「語彙道場」のiOSプロジェクトです。
**Xcodeで開いてビルド → App Store申請** まで進められる状態になっています。

必要な作業は大きく2つです。

1. Xcodeで開いて、署名（Team）を自社アカウントに設定してビルド → 3章
2. App Store Connect にアップロードして審査に提出 → 4章

申請時に入力するアプリ名・説明文・キーワードなどは、4章に**下書きを用意してあります**。
そのまま使っていただいても、修正いただいても構いません。

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | 語彙道場 |
| Bundle ID | `work.ltv.goidojo` |
| 構成 | Capacitor 7（WebView同梱型ネイティブアプリ） |
| 対応 | iPhone / iPad（縦画面固定） |
| 通信 | **なし**（完全オフライン動作） |
| データ | **端末内のみ**。外部送信・収集は一切なし |
| ネイティブ機能 | ローカル通知（今日の修行リマインド）、触覚フィードバック（正解・誤答時） |
| 収録語彙 | 681語・1,362問（語彙 / 四字熟語 / 慣用句 / 故事成語 / 敬語・仕事語 / カタカナ語 / 大人の言い換え） |
| 語彙データの出典 | **すべて自作**（辞書的な定義を参照して独自に執筆）。引用・転載なし |

### 遊び方（審査時のデモ用）

- **今日の修行**：日替わりの10問。毎日続けると連勝日数が伸びる
- **時間攻め**：60秒で何問解けるか。速く答えるほど高得点
- **真剣勝負**：1問12秒、3回間違えると終了
- **弱点復習**：間違えた語だけを再出題
- 連続正解でスコア倍率が上がり、結果画面で段位（見習い〜名人）が判定される
- 正解した語は「語彙帳」に蓄積。称号（入門〜語聖）が経験値で育つ

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 0) 日本語パス対策（CocoaPodsのエラー防止）
export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8

# 1) 依存パッケージを取得
npm install

# 2) ネイティブ依存（pod install）を統合  ※初回のみ。Xcodeが必要です
npx cap sync ios

# 3) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。
> `npx cap sync ios` は、Xcodeの無い環境で構築したため未実行です。1回実行すれば完了します（1〜3分）。
> 成功すると `✔ Updating iOS native dependencies with pod install` と表示されます。

### `npx cap sync ios` でエラーが出たら

| 表示されるエラー | 対処 |
|---|---|
| `pod: command not found` | `brew install cocoapods` を実行して再度 `npx cap sync ios` |
| `Unicode Normalization not appropriate for ASCII-8BIT` | 手順0の `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8` を実行してから再度 |
| `xcodebuild requires Xcode, but active developer directory ... CommandLineTools` | Xcodeを一度起動して初期設定を済ませ、`sudo xcode-select -s /Applications/Xcode.app` を実行してから再度 |
| `CocoaPods could not find compatible versions` | `cd ios/App && pod repo update && pod install` を実行 |

それでも通らない場合は清武までご連絡ください。エラー文をそのまま貼っていただければ対応します。

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（例: 1.0.0）と **Build**（例: 1）を設定

### 動作確認

上部のデバイス選択から実機またはシミュレータを選び ▶ で起動。

確認ポイント：
- ホーム画面で「今日の修行のお知らせ」のスイッチをONにすると通知許可のダイアログが出る
- 問題に答えると、正解で軽い振動、不正解で強めの振動がある（実機のみ）
- アプリを完全に終了して再起動しても、スコアや語彙帳が残っている

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
語彙道場 - 語彙力クイズ
```

**サブタイトル（30字以内）**
```
1日10問。大人の語彙が身につくゲーム
```

**説明文**
```
語彙道場は、クイズ形式で楽しく語彙力を鍛えるトレーニングアプリです。
四字熟語・慣用句・故事成語・敬語・カタカナ語など681語を収録。
連続正解でスコア倍率が上がり、段位が判定されるゲーム感覚で、大人の言葉が自然と身につきます。

■ 4つの稽古モード
・今日の修行：日替わりの10問。続けるほど連勝日数が伸びる
・時間攻め：60秒で何問解けるか。速く答えるほど高得点
・真剣勝負：1問12秒、3回間違えたら終わり
・弱点復習：間違えた語だけを集めて再出題

■ 7つの分野
語彙・四字熟語・慣用句・故事成語・敬語と仕事語・カタカナ語・大人の言い換え。
分野を選んで集中的に鍛えることもできます。

■ 続けたくなる仕組み
・連続正解で最大3倍のスコア倍率
・結果ごとに段位を判定（見習い〜名人）
・経験値で称号が育つ（入門〜語聖）
・出会った語は「語彙帳」に自動で蓄積。苦手な語だけを絞り込める
・毎日決まった時刻にリマインド通知

■ 効果音とBGM
正解の斬撃演出、連答で高まる音階、和風のBGM。ON/OFFの切り替えができます。

完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。
```

**キーワード（100字以内・カンマ区切り）**
```
語彙,語彙力,四字熟語,慣用句,故事成語,敬語,ビジネス用語,カタカナ語,国語,クイズ,言葉,大人の勉強,脳トレ
```

### プライバシー情報（App Store Connect「App のプライバシー」）

- **データを収集しません** を選択してください。
- 理由: 本アプリは通信機能を持たず、すべてのデータは端末内にのみ保存されます。アナリティクス・広告・トラッキングは一切ありません。
- 通知は端末内で予約するローカル通知のみで、プッシュ通知サーバーは使用していません。

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄（App Review Information の Notes）に記載すると安全です。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない。681語の問題データをアプリ内に内包）
- 端末内にデータを保存し、継続的に利用する設計（スコア・語彙帳・称号・連勝日数）
- ローカル通知（毎日のリマインド）と触覚フィードバック（正解・誤答）を実装

備考欄の記入例：
```
This app is a fully offline vocabulary quiz game with 681 words bundled in the app.
All data (scores, vocabulary book, titles, streaks) is stored on device only.
Native features: daily local notification reminder and haptic feedback on answers.
No network access, no analytics, no tracking.
```

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。

語彙を追加したい場合は `index.html` 内の `DATA` 配列に
`["語","読み","意味","分野",難易度]` の形で1行足すだけです。
