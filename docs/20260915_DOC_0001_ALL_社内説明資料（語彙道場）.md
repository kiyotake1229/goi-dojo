## 概要

「語彙道場」（大人向け語彙力クイズ）を岩崎さんに説明するためのスライド（8枚）。ねらい、遊び方（4択の例）、5つのモード、収録（7分野×3難易度・全語自作）、続ける仕掛け、現状（iOS構築済み）、申請までの残作業と費用をまとめている。

## 変更内容

### 1. 資料の置き場所を docs/ に移した

`資料/プレゼン資料/` にあったスライド一式を、project-docs の管理方式に合わせて移した。

- PDF → `docs/20260915_DOC_0001_ALL_社内説明資料（語彙道場）.pdf`
- 生成元（`gen.py`・`*.dc.html`・`canvas.json`・`deck.html`） → `tools/slides/`
- 話す台本 → `docs/20260915_DOC_0002_ALL_プレゼンの進め方（語彙道場）.md`（#0002）

### 2. スライドの構成

| No. | 見出し | タイトル |
|---|---|---|
| 01 | 表紙 | 語彙道場 |
| 02 | ねらい | 大人の語彙力は、測る機会がない |
| 03 | 遊び方 | 4択に答える。それだけで語彙が育つ |
| 04 | 5つのモード | 習慣にする入口と、燃える入口 |
| 05 | 収録 | 7分野 × 3難易度、全語自作 |
| 06 | 続ける仕掛け | 「明日も開く」を作る6つの要素 |
| 07 | 現状 | iOS は申請一歩手前。引き渡せる状態 |
| 08 | 次のステップ | 残りは実機確認と登録だけ |

### 3. 作り直す方法

`tools/slides/gen.py` の文言を直して、アプリのフォルダで次を実行する。スライド・PDF の両方が更新される。

```bash
python3 tools/slides/gen.py
```

```bash
bash docs/manager/generate_docs_json.sh
```

Claude Design（公開URL）も同じ内容にするときは、生成された `tools/slides/*.dc.html` と `canvas.json` で再公開する。
